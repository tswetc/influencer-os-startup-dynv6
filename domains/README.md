# Domains, DNS and contact routing

This directory is the **single public index** for domain status. Do not publish destination Gmail TXT payloads, login records, one-time email codes or registrar credentials.

- [Active domains](active.md)
- [Pending and investigated domains](pending.md)

Any switch of a company website domain must be coordinated with the exact website URL, HTTPS certificate, Pages CNAME, domain-matched company email, and **existing pending applications**. Publishing a different DNS target alone does not migrate mail.
