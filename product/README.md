# Product and independently viewable evidence

**Product:** Influencer OS, shipped licensed browser app v1.23. It organizes authorized reference material, reusable character passports and scene constraints, and assembles per-engine prompts for several external image/video generation workflows.

**Optional Claude functionality:** Anthropic Messages API integration with a user-provided API key (BYOK) for interpretation, critique and scene assistance. External models render resulting media. A managed Claude backend, rigorous quality benchmark or shipped MCP store listing **must not** be inferred from the landing page.
