## What exists

Influencer OS is a released, licensed creative-production web app (v1.23) for organizing authorized synthetic-character references, character passports and scenes into image/video-engine-specific prompts. It includes optional Claude Messages API assistance with a user-provided key. External providers perform image/video rendering. The public applicant website includes archived recordings of the actual application, not a live unlocked copy of the paid app.

The public site is published from **the repository root**, not from `website/`. The `website/` directory is documentation only: moving live HTML/assets there would break the currently configured Pages site unless separately planned and tested.

## Privacy and single-source rules

- Public repo: **site + safe, public-facing project description and status only**.
- Private commercial `tswetc/influencer-os`: full product source; remains separate.
- Private Google Drive “Influencer OS — Startup Applications”: legal and identity documents, application form copies/receipts, raw media and historical backups. Its contents are **not mirrored** to public GitHub.
- External third-party free-domain fork `tswetc/runs-at.dev` remains separate while the upstream domain claim is pending.

No secrets, customer data, tax identifiers, original CV, private application forms or Google Drive archive binaries should be committed here. This documentation reflects checks made on **2026-10-12**; domain and application decisions can change.
